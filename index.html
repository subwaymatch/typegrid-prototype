Get started

Ready, set, go.

Ready

Include files

Typegrid runs on plain CSS. Include typegrid.css, one file under 1KB gzipped, ahead of your own styles. 

<!-- typegrid.css -->
<link rel="stylesheet" href="css/typegrid.css">

<!-- your styles -->
<link rel="stylesheet" href="css/site.css">

Set

Change options

There are only four custom properties you need to change.

/* Desktop - Default */
--column-width: 40;
--columns: 12;
--gutter-width: 40;

/* Widescreen */
--column-width-widescreen: 60;

Go

Start coding

You're ready to dive into coding. There is nothing to compile before going live: the browser does the math, so every change shows up on the next refresh. For advanced options and other questions, please refer to the documentation below.

Overview

Benefits

Instead of generating a different grid system every time you design a new website, Typegrid allows you to generate and modify responsive grid sets on-the-go, powered by CSS custom properties.

  • Setup takes minutes. Include one file, change four numbers and start laying things out.
  • Typegrid is responsive out of the box. One set of markup covers four ranges: mobile [fluid], tablet [fluid], desktop [960px] and widescreen [varies].
  • Typegrid has no dependency. All you need is a browser. No preprocessor, no JavaScript and no build step. Even the math is handled by CSS, not by other languages.
  • Best of all, you get to change the grid configuration during development (including the number of columns)!

Basic Configuration

The four properties

Everything is derived from four unitless numbers on :root. Values are in pixels.

Property Default What it does
--column-width 40 Width of one column on desktop.
--columns 12 How many columns the grid has.
--gutter-width 40 Space between two columns.
--column-width-widescreen 60 Width of one column on large screens.

How wide is my grid?

A column and its gutter make one unit. Multiply by the number of columns and you have the container: (40 + 40) × 12 = 960px on desktop and (60 + 40) × 12 = 1200px on widescreen.

Advanced Configuration

A different grid for one section

Custom properties cascade, so the configuration does not have to be global. Set them on any element and the rows inside pick up the new grid. 

/* An 8-column grid with tighter gutters, only in the sidebar */
.sidebar {
  --columns: 8;
  --gutter-width: 20;
}

Breakpoints

The ranges switch at 768px, 1000px and 1280px. If your numbers add up to more than the screen can hold, the container simply stays fluid instead of overflowing.

Nesting

Put a .row inside any column to start a new grid there. Nested rows drop their outer padding so they line up with the parent column.

Mobile

Stack first

Below 1000px every column takes the full width, so content reads top to bottom without any extra work. Gutters shrink with the screen: 40% of your gutter width on mobile, 60% on tablet.

Opt in when you need columns

Add .mobile-N or .tablet-N next to .col-N when two things should stay side by side. 

<div class="row">
  <div class="col-3 tablet-6 mobile-6">Half on small screens</div>
  <div class="col-3 tablet-6 mobile-6">Half on small screens</div>
  <div class="col-6 hide-mobile">Not on phones</div>
</div>

.hide-mobile, .hide-tablet and .hide-desktop remove an element from a range.

Markup

Container, row, column

Three classes do all the work. Column numbers in a row should add up to 12.

<div class="container">
  <div class="row">
    <div class="col-8">Main</div>
    <div class="col-4">Aside</div>
  </div>
</div>

About

Every layout starts with a few ruled lines.

Typegrid was built in 2013, when a responsive layout meant floats, clearfixes and a calculator. It did one thing: turn four numbers into a 12-column grid you could change in the middle of a project.

The original ran on less.js. This edition keeps the idea and swaps the machinery for CSS Grid and custom properties.

For the designers, by a developer. I'm Park, a front-end developer with a passion for creating minimal yet extremely usable sites. Please visit park.is to see more works.
